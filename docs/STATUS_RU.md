# Статус проверки

## Подтверждено на одном SM-G930F

- Monitor, передняя и задняя камеры, Zoom, Speaker/Microphone и Sniper HID
  Touch использовались на реальном телефоне и Windows-ПК.
- ARM64-тесты владения кадрами DECON/MFC прошли в TWRP до очистки дерева.
- Последний BOOT с конвейером DECON загрузился; SHA-256 записи BOOT был
  прочитан обратно. При видимом движении телефон показывал примерно 54–58
  FPS вместо прежних провалов к 36–40. Пользователь подтвердил отсутствие
  этих сильных провалов.
- Новый исходный код после удаления личного серийника собран для ARM64.
  Именно эта очищенная сборка ещё не прошита и не проверена на телефоне.
- Windows x64 Monitor, Camera и Sniper helper собраны из очищенного дерева с
  фиктивным серийником; INF проверен, каталог создан. Пакет не подписан и
  не устанавливался.

## Не считать готовым

- Стабильные 60 FPS не достигнуты. Windows IDD иногда получает менее 60
  уникальных кадров в секунду, даже когда тестовая программа отправляет
  около 75 Present/s. Это отдельный нерешённый участок на ПК.
- Последний конвейер DECON не проверен на 2560×1440 после очистки.
- 120/240 FPS задней камеры не подтверждены как сквозной режим стандартного
  приложения Windows Camera; список приложения может их не показывать.
- Новый путь сборки с параметром серийника и новым подписанным манифестом
  компилируется, но пока не прошёл полный цикл подписи, установки и обновления.
- Длительная стабильность зарядки 50–80%, тепловой режим и работа на других
  телефонах не подтверждены.

Репозиторий готов к приватной публикации как исходная база. Метка «production
ready» для прошивки или установщика без перечисленных проверок была бы неверной.
