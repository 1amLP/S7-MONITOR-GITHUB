# Совместимость

## Проверенный аппарат

- Samsung Galaxy S7 **SM-G930F**, кодовое имя **herolte**, SoC **Exynos 8890**.
- У испытанного экземпляра: kernel `3.18.140-ge41817ea9198`, загрузчик
  семейства `G930FXXS1DRA5`, TWRP Recovery.
- Исходный BOOT для сборщика зафиксирован SHA-256
  `6544f30ceb74fda8be35d55664dd3570bdd5a00f453594ed1d488dab7c54233e`.
- Ядро: `7d73f82eac469c5dc1e141d5ec0f28f208a0c91449ff85acc868f5a1f2dfbc01`.
- DTB: `0c180a7249d70e7a4623a7a977a5f552670aa978fe981b992557e77c5349318a`.

Хеши проверяют **входы этой конкретной сборки**. Они не означают поддержку
любого телефона с маркировкой S7. Серийный номер проверенного экземпляра
не публикуется и должен задаваться локально при сборке.

## Не проверено

S7 edge, Snapdragon-версии, другие ревизии S7, другие ядра, заблокированный
загрузчик, Windows ARM64 и другие модели телефонов не прошли аппаратную
приёмку этой сборки. Прошивку от SM-G930F нельзя переносить на них.

## Путь к другим телефонам

Для нового устройства потребуются собственные BOOT/Recovery и запасной план
восстановления, проверка ядра и адресов, MFC/другой кодек, контроллер дисплея,
USB gadget, сенсорные узлы, аудиокодек, камера/ISP, батарея и термодатчики.
Протокол ПК и устройство меню могут служить основой; аппаратные настройки
S7 не являются универсальными.
